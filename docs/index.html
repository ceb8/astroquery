Astroquery

A set of tools for querying astronomical web forms and databases.

Installation Services By Type Documentation Services Alphabetically

Astroquery is a cooordinated package of astropy.

There are two other packages with complimentary functionality as Astroquery:
pyvo is an Astropy affiliated package, and Simple-Cone-Search-Creator to generate a cone search service complying with the IVOA standard. They are more oriented to general virtual observatory discovery and queries, whereas Astroquery has web service specific interfaces.
